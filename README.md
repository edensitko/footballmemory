# ⚽ Football Memory Game

A fun and interactive **memory game** built with **React.js**, featuring logos of various football teams. Challenge yourself to match all pairs and test your memory skills!

## 🚀 Features

- 🃏 **Memory Game Mechanics**: Flip cards to find matching pairs.
- 🏆 **Football Team Logos**: Enjoy a football-themed experience with team logos.
- 🎨 **Responsive Design**: Play seamlessly on both desktop and mobile devices.
- 🎵 **Optional Sound Effects**: Enhance gameplay with engaging sounds (if implemented).

## 🛠️ Tech Stack

- **React.js**: Frontend library for building user interfaces.
- **CSS3**: Styling the components for a visually appealing experience.
- **Vercel**: Deployment platform for hosting the application.

## ▶️ Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/edensitko/footballmemory.git
cd footballmemory
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Start the Development Server

```bash
npm start
```

Then, open [http://localhost:3000](http://localhost:3000) in your browser to play the game locally.
